# Visual showcase — asset intake and publication policy

This directory is a **placeholder for approved real screenshots**, not a gallery of manufactured UI images.

## Proposed layout

| Asset filename | Subject | Required validation |
| --- | --- | --- |
| `cco-dashboard.webp` | CCO overview/dashboard | synthetic customer data and no operational identifiers |
| `cco-inventory.webp` | CCO inventory workflow | redact SKUs/serials if they identify real operations |
| `inven3-mobile.webp` | INVEN3 mobile capture | dummy username, items, series, location |
| `inven3-reconciliation.webp` | Reconciliation view | synthetic count data, no internal system URLs |
| `gym-stats.webp` | Gym Stats interface | remove personally identifying fitness data |

## Before uploading

- Confirm ownership or authorization to publish each image.
- Blur or replace real customers, staff, prices, orders, phone numbers and inventory records.
- Remove access keys, API responses, QR contents and session information.
- Strip EXIF metadata; export optimized WebP or PNG.
- Review screenshots at full resolution, including tiny labels and backgrounds.
- Prefer 16:9 for desktop and 9:16 for mobile.
- Do not use a mockup as evidence of a real implemented feature.
- Add descriptive alternative text and project links in README after assets exist.

**No actual screenshots have been published through this placeholder.**
