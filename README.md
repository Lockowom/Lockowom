## About me

I'm **Cristopher**, an inventory analyst in Chile focused on building digital solutions for real operational challenges.

I work at the intersection of **inventory control, warehouse processes, logistics, software development and automation**, turning complex workflows into practical systems with reliable data and clear user experiences.

- **Building:** inventory applications, WMS/TMS and operational management solutions.
- **Exploring:** web applications, cross-platform interfaces, database architecture and automation.
- **Priorities:** traceability, data integrity, scalability, performance and thoughtful UX.
